# Phineas — The Finance Portal
## Claude Code Build Prompt

---

## Project Overview

Build **Phineas**, a Bloomberg/Google Finance-style personal finance dashboard. It is a React + Vite single-page application with client-side routing, deployed on Vercel. It combines live market data, RSS news feeds, and AI-generated analysis into one cohesive dashboard.

---

## Tech Stack

| Layer | Choice |
|---|---|
| Frontend | React + Vite |
| Styling | Tailwind CSS |
| Routing | React Router v6 |
| Charts | Lightweight Charts by TradingView (`lightweight-charts` npm package) |
| Stock Data | Finnhub API (free tier, 60 req/min) |
| RSS News | rss2json.com (free, no key required) |
| Stock News | Finnhub company news + Google News RSS fallback |
| AI | Google Gemini API (`gemini-1.5-flash`) |
| Watchlist Persistence | localStorage |
| Deployment | Vercel |
| Backend | Vercel Serverless Functions (for API proxying) |

## Persistent Ticker Bar (All Pages)

A slim bar fixed at the very top of every page, above the main nav.

**Left side — Market Indices (always fixed):**
- S&P 500, NASDAQ, DOW, ASX200, BTC/USD, AUD/USD
- Each shows: name, current price, % change (green/red coloured)
- Scrolls horizontally if needed on smaller screens

**Right side — User Watchlist Tickers:**
- Pulled from localStorage watchlist
- Same format: ticker, price, % change
- Clicking any ticker (index or watchlist) navigates to `/stock/TICKER`

**Data:** Finnhub quote endpoint for each ticker, fetched on page load.

## Page 2: Outlook (`/outlook`)

A dedicated full-page deep analysis view.

### Sections (top to bottom):

**1. AI Market Outlook**
- 4–6 paragraph AI-generated analysis
- Covers: macro themes, Fed/interest rate environment, sector rotation, key risks, what to watch this week
- More detailed than the homepage briefing
- Generated by Gemini using today's top headlines as context

**2. Analyst Price Targets**
- Table of user's watchlist stocks
- Columns: Ticker | Current Price | Analyst Target | Upside % | Consensus Rating (Strong Buy / Buy / Hold / Sell)

**3. Market Sentiment Indicators**
- VIX level + label (Low / Moderate / High / Extreme fear)
- Put/call ratio if available
- News sentiment score — Gemini analyses today's top 20 headlines and returns an overall market sentiment: Bullish / Neutral / Bearish with a confidence score
- Displayed as a visual gauge or score card

**4. Sector Performance**
- Grid of major sectors: Technology, Financials, Energy, Healthcare, Consumer, Industrials, Materials, Utilities
- Each sector shows % change today
- Use sector ETFs as proxies: XLK, XLF, XLE, XLV, XLY, XLI, XLB, XLU
- Data from Finnhub quote endpoint

**5. Key Events This Week**
- Upcoming Fed meetings, CPI/PPI releases, major earnings dates
- Pull from Finnhub earnings calendar for watchlist stocks
- Hardcode macro events or use a free economic calendar API if available

- MA20 and MA50 overlaid on chart

**4. Stock News**
- News stories specific to this ticker

- Fallback: Google News RSS — `https://news.google.com/rss/search?q=TICKER+stock&hl=en-US&gl=US&ceid=US:en`

- Include "✦ Summarise" button per card

**5. In-Depth AI Stock Outlook**
- Single Gemini API call combining:
  - Current price + % change
  - 52-week high/low
  - MA20, MA50 values
  - Analyst consensus target + rating
  - Last 5 news headlines for the ticker
  - Last earnings EPS vs estimate
- Output sections:
  - **Sentiment Score** — Bullish / Neutral / Bearish badge with brief reasoning
  - **Technical Summary** — 2-3 sentences interpreting chart signals
  - **AI Stock Outlook** — 3-4 paragraphs covering recent performance, key catalysts, risks, what to watch
  - **Analyst Summary** — consensus target, high/low targets, buy/hold/sell breakdown
  - **Earnings Snapshot** — next earnings date, last EPS actual vs estimate

Prompt Gemini to return structured JSON with these sections, then render each as a distinct styled panel.

## Watchlist Management

```javascript
// hooks/useWatchlist.js
const STORAGE_KEY = 'phineas_watchlist';

export function useWatchlist() {
  const [watchlist, setWatchlist] = useState(
    () => JSON.parse(localStorage.getItem(STORAGE_KEY)) || ['AAPL', 'MSFT', 'NVDA']
  );

  const addTicker = (ticker) => {
    const updated = [...new Set([...watchlist, ticker.toUpperCase()])];
    setWatchlist(updated);
    localStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
  };

  const removeTicker = (ticker) => {
    const updated = watchlist.filter(t => t !== ticker);
    setWatchlist(updated);
    localStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
  };

  return { watchlist, addTicker, removeTicker };
}
```

Default watchlist: `['AAPL', 'MSFT', 'NVDA']`

## Finnhub API Helpers

```javascript
// lib/finnhub.js
const BASE = 'https://finnhub.io/api/v1';
const KEY = import.meta.env.VITE_FINNHUB_API_KEY;

export const finnhub = {
  quote: (ticker) => fetch(`${BASE}/quote?symbol=${ticker}&token=${KEY}`).then(r => r.json()),
  candle: (ticker, resolution, from, to) =>
    fetch(`${BASE}/stock/candle?symbol=${ticker}&resolution=${resolution}&from=${from}&to=${to}&token=${KEY}`).then(r => r.json()),
  profile: (ticker) => fetch(`${BASE}/stock/profile2?symbol=${ticker}&token=${KEY}`).then(r => r.json()),
  peers: (ticker) => fetch(`${BASE}/stock/peers?symbol=${ticker}&token=${KEY}`).then(r => r.json()),
  metrics: (ticker) => fetch(`${BASE}/stock/metric?symbol=${ticker}&metric=all&token=${KEY}`).then(r => r.json()),
  recommendation: (ticker) => fetch(`${BASE}/stock/recommendation?symbol=${ticker}&token=${KEY}`).then(r => r.json()),
  companyNews: (ticker) => {
    const to = new Date().toISOString().split('T')[0];
    const from = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000).toISOString().split('T')[0];
    return fetch(`${BASE}/company-news?symbol=${ticker}&from=${from}&to=${to}&token=${KEY}`).then(r => r.json());
  },
  earnings: (ticker) => fetch(`${BASE}/stock/earnings?symbol=${ticker}&token=${KEY}`).then(r => r.json()),
};
```

## Gemini API Helpers

```javascript
// lib/gemini.js
const KEY = import.meta.env.VITE_GEMINI_API_KEY;
const BASE = 'https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent';

export async function geminiGenerate(prompt) {
  const res = await fetch(`${BASE}?key=${KEY}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      contents: [{ parts: [{ text: prompt }] }],
      generationConfig: { maxOutputTokens: 2048 }
    })
  });
  const data = await res.json();
  return data.candidates[0].content.parts[0].text;
}

// Home page — briefing + featured pick
export async function getHomeBriefing(headlines) {
  const prompt = `You are a senior financial analyst. Given these top finance headlines, do two things:
1. Write a 4-5 sentence market briefing covering the key themes and overall market mood.
2. Pick the single most significant story and return its index number (0-based).

Headlines:
${headlines.map((h, i) => `${i}. [${h.source}] ${h.title}`).join('\n')}

Respond ONLY in this JSON format with no markdown or preamble:
{"briefing": "...", "featuredIndex": 0}`;

  const text = await geminiGenerate(prompt);
  return JSON.parse(text.replace(/```json|```/g, '').trim());
}

// Outlook page — deep market analysis
export async function getMarketOutlook(headlines) {
  const prompt = `You are a senior financial analyst writing a morning market outlook report.
Based on these headlines, write a detailed market outlook covering:
1. Overall macro environment and market mood
2. Key themes and sector dynamics
3. Risk factors and potential catalysts
4. What to watch this week

Headlines:
${headlines.slice(0, 20).map(h => `- [${h.source}] ${h.title}`).join('\n')}

Write 4-6 substantial paragraphs. Be specific and insightful. Plain text only, no markdown.`;

  return geminiGenerate(prompt);
}

// Stock page — full stock analysis
export async function getStockOutlook(stockData) {
  const prompt = `You are a financial analyst. Analyse this stock and return a JSON object.

Stock Data:
- Ticker: ${stockData.ticker}
- Current Price: $${stockData.price}
- Change: ${stockData.change}%
- 52-week High: $${stockData.high52}
- 52-week Low: $${stockData.low52}
- MA20: $${stockData.ma20}
- MA50: $${stockData.ma50}
- Analyst Target: $${stockData.analystTarget}
- Analyst Rating: ${stockData.analystRating}
- Recent Headlines: ${stockData.headlines.join(' | ')}
- Last EPS: ${stockData.lastEPS} vs estimate ${stockData.epsEstimate}
- Next Earnings: ${stockData.nextEarnings}

Return ONLY this JSON with no markdown:
{
  "sentiment": "Bullish" | "Neutral" | "Bearish",
  "sentimentReason": "one sentence",
  "technicalSummary": "2-3 sentences on chart signals",
  "outlook": "3-4 paragraph stock analysis covering performance, catalysts, risks",
  "analystSummary": "2-3 sentences on analyst consensus",
  "earningsSnapshot": "2-3 sentences on earnings context"
}`;

  const text = await geminiGenerate(prompt);
  return JSON.parse(text.replace(/```json|```/g, '').trim());
}

// On-demand article summary
export async function summariseArticle(title, snippet) {
  const prompt = `Summarise this finance news article in 3-4 concise bullet points covering the key facts and implications for investors. No preamble.

Title: ${title}
Content: ${snippet}`;

  return geminiGenerate(prompt);
}
```
